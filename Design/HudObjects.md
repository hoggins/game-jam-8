# HUD-объекты — актуальная спека

Источник решений: [SourceOfTruth.md](SourceOfTruth.md). Статус кода:
[ImplementationStatus.md](ImplementationStatus.md).

## Общий контракт

Gameplay HUD не рисует отдельную модель состояния. Каждый его элемент — это
камера, направленная на настоящий физический объект в мире. Игрок может найти и
разрушить этот объект, а результат сразу виден в HUD.

Объекты не исчезают из дизайна навсегда: они участвуют в повторяющемся алгоритме
размещения и респауна большой сессии.

## Timer

- Главная повторяющаяся цель.
- Стрелка указывает направление на текущий таймер.
- Разрушен до `00:00` → время сбрасывается, старый объект очищается, новый таймер
  появляется в другом месте.
- Не разрушен → поражение и конец сессии.
- Точное стартовое время и рост сложности задаются балансом; Timer upgrade
  добавляет стартовое время.

## Arrow

- Настоящий физический объект под камерой, поворачивающийся к текущему таймеру.
- Может быть разрушен, поэтому игрок временно теряет навигацию.
- Должен снова появляться в дальнейшем маршруте согласно respawn-алгоритму.

## HP

- Физическая полоска/набор частей, показывающих текущий ресурс.
- Разрушение пополняет HP игрока.
- Объект возвращается дальше по маршруту; это повторяемый ресурс, а не permanent
  invulnerability.
- Классические floating health bars для мира отложены.

## Ammo

- Физическая полоска/набор частей, показывающих боезапас пулемёта.
- Разрушение пополняет ammo.
- Объект возвращается дальше по маршруту.

## Upgrade

- Понятная точка входа в прокачку прямо во время сессии.
- Рабочее решение встречи: физическая разрушаемая HUD-кнопка/объект.
- Разрушение открывает upgrade popup с рандомизированным выбором.
- Pause/Escape остаётся обычным, всегда доступным control.

## Размещение

Следующий Timer задаёт маршрут. Arrow, HP, Ammo и Upgrade подмешиваются между
игроком и таймером так, чтобы игрок регулярно их встречал. Алгоритм должен:

1. выбирать достижимую позицию следующего Timer;
2. не респаунить его в той же точке;
3. гарантировать понятное направление через Arrow;
4. размещать ресурсные HUD-объекты на/около маршрута;
5. не создавать неизбежную ловушку из HP/Ammo вокруг таймера;
6. очищать старые камеры, RenderTexture и физические обломки.

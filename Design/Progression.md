# Прокачка внутри сессии

Источник решений: [SourceOfTruth.md](SourceOfTruth.md). Статус кода:
[ImplementationStatus.md](ImplementationStatus.md).

## Доступ

Прокачка больше не является экраном только между короткими забегами. Игрок
получает к ней доступ во время большой сессии через понятный HUD entry point;
текущее решение — разрушить физический Upgrade-объект.

Открывается popup с несколькими случайными вариантами. Игрок покупает один из
них за монеты и продолжает текущую сессию.

## Характеристики

| Стат | Эффект |
|---|---|
| Attack | Увеличивает урон; должен иметь несколько upgrade-вариантов |
| HP | Увеличивает запас здоровья |
| Speed | Увеличивает скорость передвижения |
| Size | Увеличивает размер персонажа; камера должна отъезжать |
| Timer | Добавляет стартовое время новому циклу таймера |
| Machine Gun | Открывает/улучшает дальнобойное оружие |
| Ammo | Увеличивает запас боеприпасов пулемёта |

Speed и Size прокачиваются отдельно. Это позволяет собирать намеренно разные
архетипы, включая маленького быстрого персонажа.

## Экономика

- Валюта — монеты из текущей сессии.
- На встрече зафиксирован переизбыток валюты: игрок мог накопить около 10 000
  монет без достаточных способов потратить их.
- Решение: больше видов прокачки и более высокие цены.
- Точные цены, частота выпадения и форма price curve — задача баланса после
  сборки полного Timer respawn loop.

## Неактуальные правила

Attack не подтверждён как `RequiredMinAttackPower`-гейт объектов, уровни не
ограничены схемой 1–3, защита не определена как фиксированные −25%, а перья и
цены 25/60 больше не являются текущей экономикой.
